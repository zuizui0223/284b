# NAAMP secondary receipt v0.1

The prospectively declared temperature and seasonal-position secondary endpoints are open.

## Temperature

The frozen temperature coefficient was strongly positive:

- beta = **+0.377**
- OR per 1 SD mean run air temperature = **1.458**
- 95% OR CI = **1.373–1.547**
- p = **5.13 × 10^-35**
- n = **8,202 runs**

The complete 10-stop sensitivity is essentially identical (beta = +0.376; p = 1.02 × 10^-33).

**However, this result is not yet finalized biologically.** The converted run-mean
temperature range reaches **66.6°C**, which is physically implausible for the survey
context and indicates at least one scale/data-entry problem. The original frozen result
is retained exactly as opened; it will not be silently cleaned.

A separately frozen post-opening predictor-QC sensitivity will test whether the
temperature signal survives a physically plausible range and within each source
temperature scale.

## Seasonal shoulder

The preregistered prediction that recent rainfall synchronizes choruses more strongly
in the first/last seasonal windows is **not supported**:

- rain × shoulder beta = -0.046
- 95% beta CI = [-0.098, +0.006]
- p = **0.082**

In states with four sampling windows, the interaction changes sign and remains null
(p = 0.628).

This endpoint is closed as negative. No alternate shoulder definition will be tried.

## Current story boundary

- rainfall primary: weak positive evidence;
- temperature: strong statistical support, ecological interpretation pending predictor QC;
- seasonal shoulder: not supported;
- network reconfiguration: still unopened.
