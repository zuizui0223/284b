# Niche overlap versus demographic opposition in repeatedly censused forests — exploratory pilot

Status: prospective pilot specification before opening the new FIA outcomes. This is a separate ecological-development branch from main; the invited M1+M2 manuscript and all sealed historical endpoints are untouched.

Question: do tree species with similar historical realized climatic niches exhibit more frequent opposite **absolute adult stem-count changes** when they grow in the same physical forest plots? Alternatively, similarity may predict synchrony. No directional result is assumed. This tests demographic divergence, NOT climate-driven causality, competition or future replacement by itself.

Sources: US Forest Service FIA DataMart state CSV archives (https://research.fs.usda.gov/products/dataandtools/fia-datamart; public plot coordinates may be displaced); WorldClim v2.1 1970–2000 10-arc-minute bio1 and bio12 normals (https://geodata.ucdavis.edu/climate/worldclim/2_1/base/wc2.1_10m_bio.zip). For motivation, Laughlin & McGill 2024 Science doi:10.1126/science.adm8671 demonstrates overlapping potential niches; Kling et al. 2026 GCB doi:10.1111/gcb.71124 models recruitment, growth and mortality across US FIA plots. Neither is the response dataset in this pilot. Both use related ecological information; the new analysis is plot- and time-disjoint within the FIA network, not independently collected source streams.

Frozen exploratory design:
- ME, NH, VT (adjacent northeastern states, feasible regional pilot, not selected using outcomes). Split physical plots by SHA256 of state/unit/county/plot identifier; half reference, half validation. Reference: earliest eligible 2004–2012 visit per plot. Validation: earliest valid baseline 2013–2018 and its linked next visit through 2024, interval 4–8 years. Repeated records must link via PREV_PLT_CN and the same physical identity. No plot in both samples.
- Only national 4-subplot design, sampled forest plot, single fully accessible forest condition (proportion=1), all four sampled subplots, no recorded treatment at either visit (TRTCD1–3 nonzero excludes). Live adult stems DBH >=5 inches, standard subplot expansion factor approximately 6.018 trees/acre. These are sampled stem counts, not state-wide inventory estimates. Missing/nonsampled observations are not zeros; absence is allowed only in a qualified complete census.
- Reference climate: BIO1 in 2-degree C bins, BIO12 in 200-mm bins, bins with >=10 valid reference plots. A species needs >=40 occupied reference plots in retained bins. Estimate occurrence rate per climate bin on the shared sampled background, normalize the rates to sum to 1, then D=sum(min(p_a,p_b)). Independent reference co-occurrence Jaccard calculated from the same reference presence matrix. Report raw count histogram D as sensitivity. Neither quantity is a potential/fundamental niche or a global range estimate.
- Evaluation: both species present as >=2 adult sampled stems at baseline; pair-level primary outcome indicator (delta count A * delta count B < 0). Zero change is observed no change, not opposition; do not condition on response signs. Secondary: opposite absolute sampled basal-area changes. Species with inadequate reference coverage excluded, not assigned zero similarity. One validation interval per plot.
- Primary descriptive within-plot weighted linear probability slope for D, controlling reference co-occurrence Jaccard and symmetric baseline log-count mean and imbalance; each eligible plot total weight=1, plot-centered covariates and outcome. At least two eligible pair rows per plot for within-plot contrasts; report rank deficiency/support and absolute effect per +0.1 D. Spatial 1-degree block bootstrap (500, fixed seed) conditional on estimated reference niches; leave-one-species-out sensitivity and state-specific slopes. These are exploratory and cannot make pairs independent. Report all endpoints and both signs; do not search alternative thresholds/states for a positive result. Pair summaries for pairs with >=20 shared validation plots; no inferential claim based on number of repeated pairs.
- If source retrieval, schema, or reference coverage fails, report blocker and stop rather than substituting an outcome or climate proxy. If positive, next test true climate exposures with independent temporal climate anomalies, competition, survival/recruitment separation and independent geographical replication. If null/opposite, report honestly; do not force the hypothesis. Current ecological ledger increment 0 pending actual data/validation; pilot is exploratory, not a new sealed confirmatory endpoint.
