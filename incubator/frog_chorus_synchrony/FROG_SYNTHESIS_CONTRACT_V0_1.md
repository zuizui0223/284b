# Frog chorus synchrony synthesis contract v0.1

Frozen while the independent FrogID ERA5 validation is running and before its effect is opened.

## Decision rule

The FrogID **primary** result controls external validation.

- If the frozen primary support rule passes, the rain-synchrony association receives independent support.
- If beta is negative but the primary support rule fails, FrogID is only directionally consistent.
- If the primary is null/ambiguous, the broader cross-dataset rain claim is not made.
- If the primary is significantly positive, the independent dataset contradicts the NAAMP direction.

Sensitivity analyses can qualify robustness but **cannot rescue a failed primary**.

## Existing NAAMP boundary

NAAMP already supports a small rain association, but:
- the complete-10-stop sensitivity narrowly crosses zero;
- seasonal-shoulder amplification is unsupported;
- pairwise network densification is unsupported.

Therefore, even if FrogID validates the rain effect, the interpretation is **shared environmental activation / event-level synchrony**, not evidence that rainfall rewires pairwise species interactions.
