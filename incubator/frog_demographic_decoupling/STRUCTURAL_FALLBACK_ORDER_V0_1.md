# Structural fallback order v0.1

This note freezes what happens if the preferred Meetnetten linkage is not structurally estimable. It is written before any adult-to-offspring association is opened.

## Order

1. **Meetnetten exact-ID linkage** — same species-specific monitoring projects; adult calling protocol linked to larva/metamorph protocol by exact publisher `locationID × species × year`.
2. **PINK within-programme transition analysis** — repeated pond visits with calls plus egg/larval searches.
3. **Mohonk long-term upstream transition analysis** — adult/call → egg → larva only unless same-cohort juvenile timing is independently established.

A dataset moves down this order only for **structural reasons**: insufficient shared units, inadequate repeat visits, missing stage semantics, incompatible timing, or unidentifiable observation effort.

## Forbidden

The hierarchy cannot be changed because:
- one dataset gives a null result;
- one species gives a stronger result;
- metamorphs look more interesting than larvae;
- one environmental interaction is more significant;
- a broader claim would become easier.

This keeps the new project empirical rather than another outcome-tuned framework exercise.
