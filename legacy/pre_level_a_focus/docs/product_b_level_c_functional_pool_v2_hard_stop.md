# Product-B Level-C functional-pool v2 hard stop

## Question

After Level A closed same-target cross-source validity, v2 asked a harder question: can a dependent biological event be prospectively tested against a required **biological function**, rather than against the occurrence of one named provider taxon?

The frozen relation is

`E(k) -> F(k)`

where `E(k)` is the dependent event at a frozen biological opportunity and `F(k)` is the required function at that same key.

Examples of the admissible form are successful reproduction requiring effective pollination service or dependent development requiring a compatible host-resource function. Provider occurrence, richness, overlap, or suitability is not itself `F(k)`.

## Prospective safeguards

Before candidate search, v2 froze:

- four candidate-discovery queries and their order;
- seven admission gates;
- a 12-candidate maximum / 3-admission target hard stop;
- a ban on candidate replacement after data/source inspection;
- a ban on re-entering systems already screened in v1;
- a separate source-qualification contract;
- the rule that unavailable, missing, failed retrieval, or zero without prespecified detection adequacy cannot be interpreted as biological absence.

No focal record counts, coordinates, fitted role surfaces, cross-role statistics, or Level-A q95 tolerance were authorized during candidate admission.

## Finite screen result

The screen reached the 12-candidate maximum during the second frozen query and stopped. Queries 3 and 4 were not opened for additional candidates.

There were **0 fully admitted candidates**.

Terminal admission states were:

- 7 blocked at the exact event-to-function relation gate (G1);
- 3 passed G1-G4 and were blocked at focal evidence independence (G5);
- 1 passed G1 but was blocked because one exact relation population/site could not be frozen (G2);
- 1 was excluded because the system had already been screened in v1.

The four fresh systems that passed the hard event-to-function relation gate were:

- `YUFIV2-003` — *Yucca filamentosa*;
- `ORCHV2-006` — *Pholidota articulata* + *Coelogyne prolifera* shared orchid system;
- `CYMDV2-010` — *Cymbidium dayanum*;
- `PELTV2-012` — *Peltandra virginica*.

The first three also passed operational space, operational time, and role-estimand gates before stopping at G5. `PELTV2-012` stopped at G2.

## What changed relative to the named-provider route

Functional-pool semantics did real work. Multi-provider biology no longer fails merely because no single provider species is exclusively necessary. The hard relation can instead be stated against effective pollination or another prospectively defined biological function.

But that semantic repair does **not** create a confirmatory endpoint by itself. A relation-defining experiment cannot be reused as the focal event/function answer, and generic occurrence data cannot be relabelled as the missing independent functional channel.

The bottleneck therefore moved from **single-provider biological exclusivity** toward **independent, same-key measurement of the required function**.

## Why source qualification did not run

The source-qualification contract was frozen prospectively, but the finite candidate screen produced zero fully admitted candidates. Therefore no candidate entered source qualification and no focal source values were opened.

This means v2 contains no biological negative conclusion. In particular:

- source unavailable != function absent;
- missing != function absent;
- failed download/API != function absent;
- empty query result != function absent;
- provider absent from a database != function absent;
- zero observed service without prespecified detection adequacy != function absent.

A hard violation would require `E(k)` adequately positive and `F(k)` adequately negative under the frozen functional-absence adequacy rule. v2 never reached that stage.

## Current conclusion

The v2 hard stop is a design result, not an empirical biological endpoint. It shows that the function-level Level-C formulation is biologically better posed than the v1 single-named-provider formulation, while also showing that **fresh evidence independence is now the binding confirmatory constraint** for the screened systems.

No replacement candidate search is authorized under v2. Any future attempt must be a new prospectively frozen design rather than a rescue of this screen.

The global 284b empirical ledger remains **1**.
