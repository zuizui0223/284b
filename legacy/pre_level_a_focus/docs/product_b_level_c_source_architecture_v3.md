# Product-B Level-C v3: source architecture before outcome access

## Why v3 exists

Level-C v2 changed the biological relation from a single named provider to the required biological function, `E(k) -> F(k)`. That repaired much of the biological redundancy problem, but the finite v2 screen still closed with zero admitted endpoints because otherwise strong systems lacked fresh independent role-answer sources.

v3 does not weaken that independence requirement. It moves it earlier.

A v3 candidate is not merely a biological system. It is a prospectively identifiable three-channel architecture:

- `R`: an external source that establishes only the directional biological relation;
- `X`: an independent event-side observation stream;
- `Y`: an independent function-side observation stream.

Independence concerns observation generation, not paper titles. Republishing or refitting the same underlying observations does not create a new channel.

## Prospective finite screen

The protocol and an empty registry were committed before v3 candidate discovery. The same finite rule was retained: screen at most 12 candidates and stop early only if three pass every architecture gate. Systems already screened in Level-C v1 or v2 cannot re-enter.

The screen reached candidate 12 with two architecture-qualified systems:

- `CREMV3-007` — *Cremastra appendiculata* var. *variabilis*: an external breeding-system experiment defines the dependency; later monitoring provides same-inflorescence fruit outcomes and a distinct infrared-camera stream recording pollinia-carrying flower contacts.
- `BELV3-012` — *Belonocnema treatae* / live-oak budbreak: independent host-specificity evidence defines the biological relation; a later Dryad package exposes separate natural adult-emergence and live-oak budbreak streams.

The target of three was not reached, so candidate hunting closed at 12. No replacement candidate is permitted.

## Post-cap deviation

After the candidate cap had already closed, frozen query 4 was inadvertently issued once as a read-only metadata search. No result from that search entered the registry, received architecture scoring, entered source qualification, replaced another candidate, or opened focal values. A separate receipt quarantines all query-4 results from v3. The hard-stop result therefore records queries used for candidate admission rather than claiming the metadata query was never issued.

## Common source qualification

Before opening candidate values, one qualification contract was frozen for both architecture-qualified systems. It requires materializable X/Y sources, a common event key, direct event and function estimands, preserved provenance separation, and prospectively adequate evidence for functional absence.

Both systems stop at the same final requirement: absence adequacy.

For *Cremastra*, camera deployment covered the flowering period and fruit was counted on the monitored inflorescences, while pollinia-carrying flower contacts are a direct positive observation of pollination function. However, a camera non-detection is not yet prospectively licensed as proof that effective pollination function was absent.

For *Belonocnema*, separate natural budbreak and adult-emergence files are explicitly materializable and budbreak encodes production of ephemeral new host tissue. But metadata alone does not establish that an unobserved resource state at a proposed event key has complete enough coverage to call `F(k)=false`.

Thus both candidates terminate as `unresolved_absence_adequacy`, not biological negatives.

## What changed scientifically

The binding Level-C constraint has moved twice:

1. single-provider v1: biological alternative-provider closure;
2. functional-pool v2: fresh evidence-channel independence;
3. source-architecture v3: negative-state observation / detection adequacy.

That movement is useful even though no new empirical endpoint is opened. It identifies the next genuinely prospective requirement: design or locate an observation channel whose sampling process can establish function absence at the frozen event key, rather than treating non-detection as absence.

## Current boundary

No hard invariant, soft cross-check, process knockout, or new empirical conclusion is opened by v3. No unavailable, missing, retrieval-failed, or inadequately detected state is interpreted as a biological negative. The global 284b empirical ledger remains 1.
