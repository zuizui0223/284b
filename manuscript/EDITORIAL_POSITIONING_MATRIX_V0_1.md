# Editorial positioning matrix v0.1

Purpose: provide a concise desk-review defense for the pre-field Ecology Letters Method proposal. This document is positioning only; it does not alter scientific thresholds, candidate identity, endpoint status, or the empirical ledger.

## What is established already, and what this paper adds

| Existing approach | Established contribution | Relation to 284b | What remains specific to the proposed Method |
|---|---|---|---|
| Occupancy / detection models | Separate latent ecological state from imperfect observation when sampling identifies detection | A role-specific estimator can be used inside a relation endpoint | Does not by itself specify what relation independently generated ecological answers are entitled to test |
| Multispecies occupancy / JSDM / interaction models | Model co-occurrence, association or interaction under explicit observation models | Can generate one or more upstream answers | Statistical association is not automatically a hard biological dependency; relation choice and event-key mapping remain separate |
| LIES framework (Chadwick et al. 2024) | Typology of observation-process problems: Latency, Identifiability, Effort and Scale | Supplies a general observation-process diagnostic that can be used to assess endpoint inputs | Does not define a prospective authorization contract for composing independent ecological answers into same-target, soft cross-role or hard event-to-function endpoints |
| Ecological model adequacy (Getz et al. 2018) | Asks whether model structure and data are adequate for intended inference | Motivates answer-adequacy gates | Does not specify a relation endpoint between independently generated answers or a frozen adapter into a common biological event space |
| Independent external validation | Tests predictions on independent data | Level A is a controlled empirical example | Does not determine how validity should be escalated from same-target replication to different biological roles |
| Preregistration / Registered Reports | Freeze hypotheses, sampling and analysis before outcomes | Prospectivity enforces the contract | Prospectivity is not the novelty; the novel object is the relation-endpoint contract being frozen |

## The method object

The proposed Method is the **relation-endpoint contract**. Before focal comparison, it freezes five objects:

1. the biological relation to be tested;
2. the biological event/key space in which the relation is meaningful;
3. role-specific adapters mapping independently generated answers into that space;
4. answer-adequacy gates determining whether an endpoint input exists;
5. a calibration/opening rule determining whether relation evidence is admissible or unresolved.

For hard directional dependency `E(k) -> F(k)`, endpoint opening additionally requires that `F(k)=false` be an identifiable negative state under the observation process. A non-detection, missing value, incomplete window or failed observation cannot supply the falsifying premise merely by being encoded as zero.

## Quantitative Method result

For a qualified process with valid-key fraction `a`, the exact endpoint benchmark gives

`FPR_zero - FPR_gated = 1-a`

and

`TPR_zero - TPR_gated = 1-a`.

Thus the apparent sensitivity gained by collapsing invalid keys into biological negatives is exactly matched by the same increment in false hard violations. This is an endpoint-level decision result, not a new occupancy estimator and not a restatement of the LIES typology.

## Empirical anchor and real-system stress test

- Level A: 283/283 adequately observable fresh held-out cells remained within prospectively frozen source-discordance ceilings; five inadequate cells remained unresolved.
- Level C: two independent-answer architectures reached the negative-state calibration boundary, but focal biological values remain sealed. This is used to demonstrate the stopping rule, not to claim a completed cross-role biological result.

## Desk-review answer in one sentence

> Existing frameworks tell ecologists how to model or diagnose individual observation processes; the proposed Method tells them, prospectively and quantitatively, when independently generated ecological answers are authorized to compose into a particular biological relation endpoint, and when the endpoint must remain unopened.
